## О проекте
Интеллектуальная веб-система на базе семантической модели знаний о корейских дорамах:
- Реляционная база данных SQLite (13 таблиц в 3НФ);
- Нечёткий поиск (RapidFuzz) с автоисправлением опечаток и раскладки клавиатуры;
- Рекомендательная система (XAI) на основе сюжетных тропов и косинусного сходства;
- Автономная фоновая синхронизация метаданных.

## Стек технологий
- **Backend:** Python 3.11, FastAPI, Uvicorn, RapidFuzz, APScheduler.
- **Database:** SQLite 3.35+ (DDL-схема в `sql/schema.sql`).
- **Frontend:** HTML5, CSS3, JavaScript (ES6).
